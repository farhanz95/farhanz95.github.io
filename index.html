Git Deployment Workflow

Deploy to staging without disrupting local development — using git worktree

Scenario: Deploy ke staging-adobe (remote: origin-adobe) tanpa kacau branch semasa yang sedang digunakan. Kaedah ini guna git worktree untuk create folder berasingan — boleh deploy dan continue kerja serentak.
1
Tukar ke branch staging — pastikan bukan branch yang tengah digunakan (origin-adobe/staging).
$ git checkout staging
2
Create folder project-deploy menggunakan branch staging-adobe via git worktree.
$ git worktree add ../project-deploy staging-adobe
3
Masuk ke folder project-deploy — boleh open new tab terminal untuk senang.
$ cd .. && cd project-deploy
4
Fetch semua remote branches dari dalam folder project-deploy.
$ git fetch --all
5
Merge branch staging (dari Bitbucket) ke dalam staging-adobe di folder project-deploy.
$ git merge staging
6
Push ke origin-adobe untuk start deployment. Lepas push, boleh tinggalkan tab ini dan sambung kerja di branch lain.
$ git push origin-adobe staging-adobe:staging
Selepas deploy selesai
7
Buang folder project-deploy untuk free up disk space selepas deployment selesai.
$ git worktree remove ../project-deploy
💡 Why worktree? Git worktree membenarkan dua branch checkout serentak dalam dua folder berbeza — tanpa perlu git stash atau tukar branch. Selamat untuk deploy sambil kerja on feature branch yang berbeza.
